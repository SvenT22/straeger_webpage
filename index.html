What I specialise in

Microsoft PowerPlatfom

Die Microsoft Power Platform ermöglicht es, mit wenig oder gar keiner Programmierung individuelle Business‑Apps, automatisierte Workflows und interaktive Dashboards zu erstellen. Durch die enge Integration von Power Apps, Power Automate, Power BI und Power Virtual Agents können Daten aus verschiedensten Quellen zusammengeführt und in Echtzeit analysiert werden. Damit lässt sich die Produktivität steigern, Prozesse beschleunigen und Entscheidungen fundierter treffen – alles innerhalb einer sicheren, cloud‑basierten Umgebung.
Microsoft PowerPlatform

n8n.io

Mit n8n lassen sich ganz viel Abläufe in Ihrem Unternehmen Automatisieren. Das verarbeiten von Formular‑Anfragen, das Erstellen von Rechnungen oder das Synchronisieren von Kundendaten zwischen Ihren Systemen. Ich setze das Tool für Sie ein, erstelle die passenden Workflows und passe sie exakt an Ihre Geschäftsprozesse an. Sobald der Ablauf definiert ist, übernimmt n8n die Arbeit im Hintergrund, Ihre Daten bleiben sicher auf Ihrem Server und Sie profitieren von weniger manuellen Schritten, weniger Fehlern und mehr Zeit für das Wesentliche.
n8n

EspoCRM

EspoCRM ist ein webbasiertes CRM, das Ihnen hilft, Kontakte, Leads und Verkaufschancen zentral zu verwalten. Mit einer intuitiven Drag‑and‑Drop‑Oberfläche können Sie Felder, Pipelines und Automatisierungen ohne Programmierkenntnisse an Ihre Prozesse anpassen. Die offene API ermöglicht leichte Integration in E‑Mail‑Programme, Buchhaltung oder Marketing‑Tools, sodass alle Daten an einem Ort zusammenfließen. Neben einer kostenlosen Community‑Edition gibt es kostenpflichtige Varianten mit erweiterten Funktionen und Support – ideal für kleine bis mittelgroße Unternehmen, die ein flexibles und kostengünstiges CRM benötigen.
EspoCRM

Paperless-ngx

Paperless ngx wandelt eingehende Dokumente automatisch in durchsuchbare PDFs um, versieht sie mit Metadaten und speichert sie sicher auf Ihrem eigenen Synology‑NAS. Durch die offene API lässt sich das System nahtlos in die Power Platform, n8n‑Workflows und das CRM EspoCRM integrieren, sodass Dokumente überall dort verfügbar sind, wo Sie sie benötigen. So behalten Sie die volle Kontrolle über Ihre Daten, reduzieren manuelle Aufwände und schaffen eine zentrale, leicht zugängliche Wissensbasis – ganz im Sinne einer dezentralen, datenschutzkonformen Unternehmensstrategie.
